# IBM DBSCAN & HDBSCAN Clustering

![Workflow](images/dbscan-workflow.png)

## Project Overview

This project demonstrates Density-Based Clustering using DBSCAN and HDBSCAN with Python and Scikit-learn.

Unlike K-Means, these algorithms do not require specifying the number of clusters beforehand and can identify clusters with arbitrary shapes while detecting noise (outliers).

This project is based on the IBM Machine Learning with Python course.
